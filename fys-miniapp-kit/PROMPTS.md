# Готовые задачи для Claude

Как пользоваться: открыть claude.ai/code, выбрать этот репозиторий, скопировать задачу, заменить «…» своим и отправить. Claude покажет, что поменял. Если всё верно — Create PR, затем на GitHub Merge pull request → Confirm merge. Через 1–2 минуты правка на сайте.

Правило: одна задача — одна тема. Так проще проверять и откатывать.

---

## 1. Ссылки и время эфира

```
В index.html в начале скрипта поставь:
LESSON_1 = …
LESSON_2 = …
LIVE_URL = …
CHANNEL_URL = …
LIVE_TIME = … (например: '19:00 по Москве')
LIVE_WHEN = … (например: '3 декабря, 19:00 по Москве')
Больше ничего не меняй. Покажи, какие строки поменял.
```

Перенести даты похода:

```
Поход переносится: сборы …, урок 1 …, урок 2 …, ночёвка …, эфир у костра … (день недели).
Поменяй даты во всех местах: DATES, подзаголовок обложки, задачи в TASKS, плашка эфира liveBanner, числа недели и огонёк в календаре routeBlock. Больше ничего не меняй.
```

## 2. Тексты

```
В дне … в блоке «…» замени текст:
было: «…»
стало: «…»
Дизайн не меняй.
```

```
Вот тексты команды на день …: (вставить)
Замени вступление дня и задачи в календаре на эти формулировки. Свои слова не добавляй.
```

```
Замени конспект урока … (NOTES) на эти советы: (вставить)
Свои слова не добавляй. Больше ничего не меняй.
```

## 3. Новая задача или новый блок

```
В день … добавь задачу в «Что нас ждёт»:
заголовок: «…»
пояснение: «…»
Если в дне есть блок, к которому она относится, сделай кнопку «перейти ↓».
Больше ничего не меняй.
```

```
В день … после блока «…» добавь новый блок «…» с пояснением «…».
Поля: … (например: одно поле для ответа, список, чек-лист из пунктов …).
Ответы должны сохраняться. Стиль как у соседних блоков. Больше ничего не меняй.
```

## 4. Страница «Экспедиция»

```
На странице «Экспедиция» замени текст письма Алины на этот: (вставить)
Ссылку «Узнать про экспедицию» поставь: …
Цены и тарифы не добавляй. Больше ничего не меняй.
```

## 5. Фото

Фото удобнее менять без Claude: в репозитории открыть папку `img` → Add file → Upload files → перетащить файлы с теми же именами (`hero.jpg`, `hero-m.jpg`, `moon.png`, `night.jpg`, `sunset.jpg`, `dna.jpg`, `fire.jpg`) → Commit changes. Ширина до 2000 px, вес до 500 КБ.

## 6. Проверка глазами участниц

```
Пройди мини-апп глазами шести типов участниц из навыка fys-telegram-miniapp. Для каждой выпиши, где она застрянет, что ей непонятно и что мешает дойти до эфира и до экспедиции.
Собери общий список правок по важности. Пиши честно: это оценка модели, а не опрос живых людей, продажи она не предсказывает.
Ничего не меняй, пока я не выберу пункты.
```

## 7. Скриншоты для команды

```
Открой index.html в браузере на ширине 390 px и сделай скриншоты всех пяти дней и страницы «Экспедиция», заполнив поля примером участницы «Аня». Сложи их в папку screens/ и покажи мне. Код мини-аппа не меняй.
```

Если у Claude в этой задаче нет браузера, проще записать экран телефона.

## 8. Новый мини-апп из этого шаблона

Сначала: этот репозиторий → Settings → галочка Template repository (один раз). Потом Use this template → Create a new repository. Включить GitHub Pages и дать Claude доступ к новому репозиторию.

```
Используй навык fys-telegram-miniapp.
Это копия мини-аппа «Зимний поход». Сделай из него новый мини-апп по брифу ниже.
Дизайн, шрифты и все интерактивы оставь. Тексты бери только из моих материалов.
Сначала задай уточняющие вопросы, потом покажи план дней и только после моего «да» меняй файлы.

БРИФ: …
ТЕКСТЫ ПО ДНЯМ: …
```

## 9. Откатить правку

Если правка уже на сайте: на GitHub открыть принятый запрос на изменение → Revert → принять новый запрос. Или в Claude:

```
Верни index.html к состоянию до последней правки «…». Больше ничего не меняй.
```
