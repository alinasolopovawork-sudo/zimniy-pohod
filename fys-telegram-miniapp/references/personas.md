# Шесть типов участниц для проверки

Нужны, чтобы пройти мини-апп чужими глазами и найти непонятные и неудобные места. Это оценка модели, а не опрос живых людей.

| Тип | Что ей важно | Где обычно спотыкается |
| --- | --- | --- |
| Новички, хотят вести блог | понять, с чего начать, и не испугаться | много полей в первый день, непонятно, когда уроки |
| Эксперты, видео для продаж | быстро и по делу, мало времени | длинные блоки, «зачем мне это» |
| Уже снимают | новые приёмы, стиль Алины | слишком простые задания |
| Мамы, снимают для себя и близких | тепло, семья, память | боятся, что «не их уровень» |
| Хотят зарабатывать на видео | доход, клиенты, кейсы | не видят связи с заработком |
| Скептики | доказательства | общие слова без примеров |

Для каждого типа выпиши: где застрянет, что непонятно, что мешает дойти до эфира, что мешает купить. Собери общий список правок по важности: сколько участниц задевает и насколько сильно.
