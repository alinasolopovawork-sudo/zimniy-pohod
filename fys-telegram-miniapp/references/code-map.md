# Карта кода эталона (`index.html`)

Всё в одном файле: `<style>`, разметка обложки и маршрута, один `<script>`. Картинки в `img/`.

| Что | Где в скрипте | Что менять под новый мини-апп |
| --- | --- | --- |
| Ссылки и время эфира | `LESSON_1`, `LESSON_2`, `LIVE_URL`, `CHANNEL_URL`, `LIVE_TIME`, `LIVE_WHEN` в начале скрипта | ссылки, время |
| Дни | `DAYS`, `DATES`, `HIKE_YEAR` | ключи адресов, названия, иконки, подписи, вступления, даты |
| Задачи | `TASKS`, `LINKS`, `LINK_TXT`, `LINK_WAIT` | задачи по дням, подписи кнопок |
| Календарь | `CAL_VIEW`, `routeBlock()` | подписи и фото этапов, числа недели, огонёк дня эфира |
| Конспекты уроков | `NOTES`, `notesBlock()` | советы к урокам |
| Модель данных | `blank()` | поля под новые блоки (без этого не сохранятся) |
| Блоки дней | `day0()`…`day4()`, `card()`, `stp()`, `field()`, `list()`, `checks()` | состав блоков |
| Якоря и фото блоков | `SID`, `NIGHT`, `SUNSET` | заголовок нового блока → id; фото внизу |
| Карточки уроков и эфира | `lessonCard()`, `liveBanner()` | названия, дата эфира |
| Обложка | `landscape()`, `TINTS`, `fitLand()`, `img/hero.jpg`, `img/hero-m.jpg`, `img/moon.png` | фото, точки тропы `pts`, оттенки по дням |
| Письмо себе | `letterBlock()`, `LETTER_OPEN`, `LETTER_OPEN_TXT` | дата вскрытия |
| Страница курса | `expedition()`, `EXP`, `EXP_URL` | текст письма автора, ссылка |
| Хранение | `STORE`, `APP`, `load()`, `persist()` | для нового мини-аппа сменить `STORE` и `APP`, чтобы не смешать данные |

## Где стоят даты

В эталоне даты записаны не только в `DATES`. При переносе меняй всё разом:

- `DATES` (числа, месяцы, дни недели);
- подзаголовок обложки в разметке (`29.11 — 03.12`);
- `TASKS` — задачи про эфир («3 декабря, четверг», «3 декабря»);
- `liveBanner()` — «3 декабря, четверг»;
- `routeBlock()` — числа недели `nums` и огонёк «🔥 3.12»;
- `render()` — год в строке даты (`.26`).

Число дней не обязано быть 5: при изменении поправь `DAYS`, `DATES`, `TASKS`, `CAL_VIEW`, массив функций дней в `render()`, сетку недели в `routeBlock()`, расчёт `left` в `liveBanner()` и число колонок маршрута в CSS (`.stops`).
