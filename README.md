# Зимний поход · мини-апп Film Your Story

Мини-апп для Telegram к бесплатному мастер-классу Алины Солоповой. Пять остановок с 29.11 по 03.12: сборы, в путь, привал, ночёвка, у костра. Эфир у костра 3 декабря, четверг. После костра открывается страница «Экспедиция»: пропуск с отрывным корешком и письмо от Алины со ссылкой на курс.

## Что где лежит

| Файл | Что это |
| --- | --- |
| `index.html` | сам мини-апп: дизайн, тексты, интерактивы, всё в одном файле |
| `img/hero.jpg`, `img/hero-m.jpg` | обложка: ночные горы и путники с фонариками (`hero-m` — для телефона, без луны) |
| `img/moon.png` | луна поверх обложки на телефоне |
| `img/night.jpg`, `img/sunset.jpg` | фото внизу блоков и в календаре |
| `img/dna.jpg` | фото дня «Сборы» в календаре |
| `img/fire.jpg` | фон плашки «Эфир у костра» |
| `CLAUDE.md` | правила для Claude: дизайн, устройство кода, что нельзя трогать |
| `PROMPTS.md` | готовые задачи для Claude |
| `.claude/skills/fys-telegram-miniapp/` | навык, по которому Claude собирает новые мини-аппы в этом стиле |

## Как это работает

1. Файлы лежат в этом репозитории.
2. GitHub Pages публикует их как сайт: `https://<логин>.github.io/<репозиторий>/`.
3. Кнопка меню Telegram-бота открывает этот сайт внутри Telegram.
4. Правки делаются через Claude Code на claude.ai/code: задача словами → Create PR → на GitHub Merge pull request → Confirm merge → через 1–2 минуты правка на сайте.

## Перед запуском

- В начале скрипта в `index.html` вставить ссылки: `LESSON_1`, `LESSON_2`, `LIVE_URL`, `CHANNEL_URL`, и время эфира `LIVE_TIME`, `LIVE_WHEN`. Пока они пустые, участницы видят «ссылка появится в день урока».
- Проверить ссылку «Узнать про экспедицию» (`EXP_URL`).
- Токен бота и данные участниц в репозиторий не класть: он открытый.
