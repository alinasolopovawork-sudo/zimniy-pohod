# Дизайн Film Your Story для мини-аппов

Источник — макет команды Алины «Зимний поход». Всё задано CSS-переменными в `:root` эталона.

## Цвета

| Переменная | Цвет | Где |
| --- | --- | --- |
| `--night` | #0f1c33 | фон страницы |
| `--night-2` | #16284a | кружки маршрута, подложки |
| `--snow` | #f4f7fb | основной текст |
| `--snow-dim` | #b4c2d8 | пояснения, подсказки |
| `--beige` | #efe8da | календарь, конспект урока, пропуск |
| `--yellow`, `--fire` | #efdb55 | тропа и метки на обложке, рамка заголовка, главные кнопки |
| `--rose` | #f4b5d4 | плашки дней, текущая остановка, первая задача |
| `--rose-deep` | #a8447a | марка и штемпель письма, подписи на пропуске |
| `--pine` | #6f8c3e | отметка «готово» |
| `--olive` | #7a9440 | выполненные задачи в календаре |

## Шрифты

- IBM Plex Mono 600, ПРОПИСНЫЕ — заголовки страницы, дней, блоков, плашки, даты.
- Inter — всё остальное. Курсив — вступления дней, письмо себе, подсказки в полях.

## Элементы

- **Обложка.** Фото `img/hero.jpg` (на телефоне `img/hero-m.jpg` с отдельной луной `img/moon.png`). Поверх — жёлтая тропа с двумя метками и оттенок света по дню (`TINTS`: вечер, рассвет, закат, ночь, костёр). Снег на canvas. Заголовок моноширинным в жёлтой рамке, под ним розовая метка с датами и подзаголовок. Если участница выбрала свою картинку «на обложку», она заменяет горы.
- **Маршрут.** Тёмная плашка, остановки в кружках с иконками, дата и счётчик задач. Текущая розовая, пройденная с зелёным значком ✓. На телефоне ряд прокручивается вбок.
- **Плашка дня.** Розовый чип «день N · ДД.ММ», большой заголовок, вступление курсивом.
- **Календарь «Что нас ждёт».** Бежевая карточка-телефон: неделя с подписями этапов, ниже задачи дня карточками (первая розовая, эфир с огоньком, выполненные зелёные), счётчик «N из M задач готово».
- **Конспект урока.** Бежевая карточка с четырьмя пронумерованными советами.
- **Блоки-разговоры.** Подпись блока, вступление, шаги с номерами 01, 02… Часть блоков с фото внизу (`ph-night`, `ph-sunset`).
- **Плашка «Эфир у костра».** Фото `img/fire.jpg`, дата, отсчёт дней, кнопка.
- **Отметки.** Круг; отмечено — зелёный круг с белой галочкой. Звёздочки не использовать.
- **Кнопки.** Главная жёлтая с тёмным текстом. Второстепенные белые или прозрачные.
- **Письмо.** Бумага, марка и круглый штемпель, текст Inter курсивом. Запечатанное — конверт с печатью FYS.
- **Пропуск.** Бежевый, слева данные участницы (имя, идея), справа корешок с номером. После «Забрать билет» корешок оторван, ниже письмо автора.
